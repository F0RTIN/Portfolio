# Portfolio — Alexandre Fortin · Creative Technologist

Portfolio personnel conçu pour être hébergé directement sur **GitHub Pages**.

## ✨ Caractéristiques & Interactions

- **Direction Artistique Monochrome** : Interface sobre, moderne et élégante en noir, blanc et nuances de gris (*obsidian glassmorphism*), sans couleurs vives superflues.
- **Présentation Directe & Authentique** : En haut de page, présentation rédigée à la première personne reflétant fidèlement le profil d'ingénieur R&D, complétée par la formation (ESILV & IFT) et la matrice de compétences clés (CAO Onshape, prototypage rapide, PCB KiCad, microcontrôleurs, rétro-ingénierie, C/C++, OpenCV).
- **Bilingue Instantané (FR | EN)** : Bouton commutateur `EN | FR` en haut à droite permettant de traduire en temps réel l'intégralité du site (présentation, projets, popups, expériences et compétences) avec mémorisation du choix.
- **Sélecteur de Parcours Segmenté** : Choix interactif entre **PROJETS** (8 réalisations) et **EXPÉRIENCE** (parcours professionnel).
- **Projets Réalisés Riches en Visuels** :
  - **DaVinciBot** : Robot autonome de compétition pour la Coupe de France de Robotique (photos d'arène, d'électronique et modélisation).
  - **Mécanisme de Serrage BOA** : Rétro-ingénierie CAO complète d'un mécanisme micrométrique à molette pour la recherche médicale (vue éclatée 3D, coupes transversales).
  - **Mobilier sur Mesure** : Conception en jumeau numérique sous contraintes d'espace et d'ébénisterie (rendu d'architecture d'intérieur, modèle 3D).
  - **Pétale** : Luminaire modulaire sous enveloppe financé sur Kickstarter (visuels, logos, animations, mockups).
  - **CRT Matière Analogique** : Circuit bending de tube cathodique pour la conférence CHI 2025.
  - **Braille en Mycélium** : Recherche en bio-design et dômes tactiles vivants à l'IFT (photos de laboratoire et coupes CAO).
  - **MNIST & Moteur 3D WebGPU** : Expérimentations web interactives avec boutons **⚡ DÉMO** pour tester directement dans le navigateur.
- **Modale Galerie Interactive** : Navigation photo avec flèches gauche/droite, clavier et miniatures cliquables.
- **Timeline Professionnelle Harmonisée** :
  - Dispositions homogènes pour **iFollow**, **Super U** et **ArianeGroup** avec la mention/badge sous le titre du stage.
- **100% Responsive** : Interface fluide et adaptée aux grands écrans, ordinateurs portables et smartphones.

## 🚀 Déploiement sur GitHub Pages

1. **Publier sur GitHub** :
   ```bash
   git add .
   git commit -m "Update portfolio: monochrome design, rich galleries & responsive layout"
   git push origin main
   ```
2. **Activer GitHub Pages** :
   - Rendez-vous sur votre dépôt : **Settings** > **Pages**.
   - Sous **Build and deployment** > **Source**, choisissez **Deploy from a branch**.
   - Sélectionnez la branche `main` et `/ (root)`, puis cliquez sur **Save**.
